# AnOOPlan 3.2.0 — «Полная смета»

**Дата:** 2026-11-24 · **versionCode:** 52 · **minSdk 24 / targetSdk 35** · без `INTERNET`

**APK:** `AnOOPlan-3.2.0.apk` · сертификат не менялся — обновление ставится поверх 3.1.0.

## Кратко для RuStore

В AnOOPlan 3.2.0:

- **Смета учитывает комплектацию КНС.** На экране сметы появился раздел «Комплектация КНС»:
  для фитингов и креплений (заглушки, соединители, крепёж) задаётся норма расхода на 1 метр
  трассы и цена — приложение само считает количество по метражу лотков. Нормы задаёт только
  пользователь: без них смета считается ровно как раньше, программа ничего не подставляет сама.
- **Отдельный лист «Подписи» в печати.** В настройках печати появился раздел «Лист подписей»
  (по умолчанию выключен): подписи «Составил/Проверил» и итог журнала выносятся на отдельный
  лист комплекта с записью в оглавлении.
- Когда комплектация задана, примечание «фитинги и крепления не считаются» в документах
  заменяется на ссылку на раздел сметы — документ не противоречит сам себе.

## Технические детали

- **Модель:** `Project.fittings?: FittingRule[]` (`name`, `unit`, `perMeter`, `price`, `note`),
  необязательное поле; миграция пропускает старые проекты без изменений, пустой список
  не хранится. Нормализация `normalizeFittings` — по образцу работ по видам: мусор
  отбрасывается, дубли id разводятся, нечисловые/отрицательные значения — `null` (неизвестно).
- **Расчёт:** раздел «Комплектация КНС» в `estimate()` появляется только при заданных нормах;
  количество строки — `perMeter ×` итоговый метраж КНС из `specificationKnS`. Раздел входит
  в материалы, работы процентом считаются от новой суммы. Без норм результат `estimate()`
  бит-в-бит прежний (проверено тестом).
- **Документы:** смета в PDF/XLSX получает строки раздела автоматически; оговорки в «Схеме
  трасс» и «Спецификации КНС» условные — «не считаются» печатается только когда норм нет.
- **Лист «Подписи»:** новый `JournalSectionId.signaturesSheet`, не входит в набор по умолчанию
  (`DEFAULT_JOURNAL_SECTIONS` и стартовый выбор панели печати). При включении —
  `Renderer.signatures(project, ownSheet: true)` всегда открывает новый лист и возвращает его
  номер для оглавления; без флага поведение байт-в-байт прежнее.
- **Валидация:** серверный `assertProject` проверяет `project.fittings` (422 на мусор).
