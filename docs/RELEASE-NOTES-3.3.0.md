# AnOOPlan 3.3.0 — «Здания и телефония»

**Дата:** 2026-11-24 · **versionCode:** 53 · **minSdk 24 / targetSdk 35** · без `INTERNET`

**APK:** `AnOOPlan-3.3.0.apk` · сертификат не менялся — обновление ставится поверх 3.2.0.

## Кратко для RuStore

В AnOOPlan 3.3.0:

- **Несколько зданий в одном проекте.** На вкладке «Этажи» появилась кнопка «＋ Здание»:
  этажи группируются по зданиям, здание можно переименовать прямо в списке и удалить —
  этажи при этом остаются и просто становятся «без здания». В свойствах этажа задаётся
  его здание, а списки этажей в свойствах оборудования и трасс группируются по зданиям.
- **Новое оборудование: АТС и IP-телефон.** В свойствах оборудования появились типы
  «АТС» и «IP-телефон» с собственными значками на плане (и в PDF): АТС — корпус с
  дисплеем и портами, телефон — аппарат с трубкой. Цвета значков различаются, как у
  остальных типов.
- Старые проекты открываются без изменений: деление на здания необязательно, проект
  без зданий выглядит и работает ровно как раньше.

## Технические детали

- **Модель:** `Project.buildings?: Building[]` (`id`, `name`) и `Floor.buildingId?: string | null` —
  необязательные поля; проекты без них загружаются бит-в-бит как раньше. Пустой список
  зданий не хранится: «зданий нет» — это отсутствие поля.
- **Миграции:** записи зданий без id отбрасываются, дубли id разводятся суффиксом,
  имена обрезаются; привязка этажа сохраняется только при существующем здании —
  висячая ссылка отбрасывается, а не превращается в фантомное здание.
- **Сервер:** `assertProject` проверяет `project.buildings` (непустые id/name, уникальность
  id в общем пространстве идентификаторов) и ссылку этажа на здание — фантомное здание
  даёт 422.
- **UI:** сайдбар группирует этажи по зданиям (чистый помощник `groupFloorsByBuilding`),
  заголовок здания — поле переименования и кнопка удаления (этажи сохраняются); выбор
  здания в свойствах этажа; `floorSelect` группирует варианты через `optgroup`.
- **Иконки:** в общий набор (план, список объектов, PDF) добавлены `pbx` и `phone`
  (глифы 24×24, fill-rule evenodd); цвета по умолчанию — `#2f9e63` и `#dc5071` из палитры
  пресетов. Распознавание по типу: «АТС»/«Мини-АТС»/«IP-АТС» → `pbx`,
  «телефон»/«phone» → `phone`; «Шкаф АТС» остаётся шкафом. Чипы типов в свойствах
  оборудования дополнены.
