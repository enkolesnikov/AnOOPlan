# План развития AnOOPlan — Android-first

Роадмап от **2026-10-24** после аудита и решений владельца: фокус — **эффективность Android-приложения
и процесса разработки**. Облако — в планах (дальняя перспектива); в `main` его нет. Версия **2.1.0**
выпущена: скорость, размер и разгрузка интерфейса. Следующая — **2.2.0 «Поле и доступность»**.

## 1. Что сделано в 2.1.0

- **APK легче на 0,4 МБ (1,85 → 1,46 МБ).** Шрифты PDF — сабсеты PT Sans (латиница, кириллица,
  цифры, типографика) ≈65 КБ вместо ≈450 КБ; по требованию OFL переименованы в «AnOOPlan Sans».
  PDF по-прежнему собирается офлайн с кириллицей.
- **0 известных уязвимостей.** `xlsx` 0.18.5 (high ReDoS без фикса) заменён официальной сборкой
  SheetJS 0.20.3 (tarball `cdn.sheetjs.com`); формат XLSX и API не изменились.
- **Удалён второй PDF-движок.** `server/export.ts` и `pdfkit` (≈5,9 МБ зависимостей, системные TTF,
  ошибка 503) убраны: экспорт CSV/XLSX/PDF полностью клиентский, локальный сервер — только хранение.
- **`App.tsx` разгружен: 1 429 → 35 строк.** Экраны, панели, шторки и хуки логики — в `src/ui/`
  (27 файлов, ≈1 860 строк); поведение, разметка и стили не менялись (смоук и E2E зелёные).
- **Бюджеты в CI:** `npm run coverage` (пороги 93/85/92 %), `npm run size` (JS ≤460 КБ, CSS ≤40 КБ),
  `npm run status` — быстрый статус проекта вместо ручной синхронизации счётчиков.
- 2.0.0 (ранее) — откат к офлайну, один CI-workflow на push, версия из `package.json`, ручные Pages/APK.

### 2.2.0 — «Поле и доступность» (следующая)

**Цель:** приложение должно быть удобным и предсказуемым на реальных телефонах и в поле.

- **Доступность:** учитывать системный размер шрифта (`textZoom`), тёмная тема и высокий контраст;
  проверить фокус/aria после разбиения на `src/ui`.
- **Память и большие листы:** бюджет рендера 6–8 Мпикс с понятным предупреждением; проверить A1/A0
  на эмуляторе с ограниченной памятью.
- **Векторный план в PDF** вместо растра 1600 px — качество печати и размер файла.
- **Диагностика в интерфейсе:** занятое место, версия WebView, экспорт журнала.
- **Инженерный долг:** `tests/fixtures.ts` (12 тестов), прямые тесты `src/ui`-хуков, распил `AppUi`
  на под-объекты, по возможности уменьшить `node_modules`.
- **Ручные сценарии Android:** три обязательных — запуск/проект, `.anooplan` через `content://`,
  печать/шаринг; остальное — автотестами.

**Готово, когда:** `textZoom` и тема работают, память рендера в бюджете, векторный план в PDF,
фикстуры и тесты хуков добавлены, покрытие не ниже 95 %, APK не вырос, тесты/смоук/E2E зелёные.

### 2.3.0 — «Документы и расчёт»

- Печатные формы: полный штамп ГОСТ 2.104, оглавление на второй странице для длинных документов.
- Смета: НДС, отдельные виды работ, единицы измерения; КП по разделам.
- Заполнение лотка: размеры на сегмент, коэффициент укладки/пучков, явная площадь плоских кабелей.
- Сравнение снимков версий (diff).

**Готово, когда:** заказчику можно отдать документ без ручной правки, смета покрывает типовые
расчёты, а лотки считаются по сегментам.

## 5. Что не делаем

- **Облако и real-time** — в планах на дальнюю перспективу; не возвращаем «между делом».
- **Kotlin-переписывание** — только при ежедневном стилусе/A1+ или если WebView начнёт блокировать
  развитие; промежуточный вариант — нативная растеризация PDF.
- **Google Play, подписки, маркетплейс** — не влияют на основной сценарий.
- **Автодеплой Pages** — только вручную; решение «убрать Pages совсем» — за владельцем.

## 6. Определение готовности итерации (DoD)

1. `npx tsc --noEmit`, `npm test`, `npm run coverage`, `npm run size`, `npm run smoke`,
   `npm run test:ui` — зелёные; покрытие не упало.
2. Бюджеты: CI на push ≤110 с; стартовый бандл JS ≤460 КБ / CSS ≤40 КБ; APK ≤1,5 МБ;
   0 high-уязвимостей.
3. APK собран локально, подпись и сертификат совпадают; версия/`versionCode` — из `package.json`;
   установка и запуск проверены на эмуляторе; для Android-изменений — нужный ручной сценарий.
4. README («Что нового»), HANDOFF, ROADMAP обновлены; статус — `npm run status`, счётчики вручную
   не синхронизировать.
5. **Скриншоты релиза: 1–3** (минимум один, максимум три), приложены к GitHub Release и в отчёт
   сессии; для невизуального изменения — один скриншот подтверждения.
6. Аннотированный тег `vX.Y.Z`, GitHub Release с APK, CI на `main` зелёный.

## 8. Риски

- **Сабсет шрифтов** не содержит редких/экзотических глифов: пользовательский текст с ними может
  напечататься не полностью. Базовые кириллица/латиница гарантированы; при жалобе — расширить
  набор и пересобрать сабсет (OFL: переименование семейства сохранить).
- **XLSX-зависимость** — tarball с `cdn.sheetjs.com`: `npm ci` требует доступ к этому хосту.
  При недоступности — временно вендорить tarball в репозиторий (осознанное решение).
- **`src/ui`** использует coarse `AppUi`: дальнейший распил — только типовой рефакторинг под
  смоуком/E2E, без изменения поведения.
- **Веб-версия без автодеплоя** может отставать от `main` — публиковать вместе с релизом либо
  убрать Pages по решению владельца.
- **Возврат к облаку** — только отдельным решением владельца.
