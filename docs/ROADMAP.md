# План развития AnOOPlan — 2.0.0 «оптимизация Android»

Роадмап пересобран **2026-10-24**. Фокус — **эффективность Android-приложения и процесса разработки**.
Версию **2.0.0** занимает эта оптимизация, поэтому вся нумерация ниже начинается с 2.1.0.

## 1. Что сделано в 2.0.0

- **Полностью офлайн.** Сетевые модули и аккаунты убраны из кода, `INTERNET` не запрашивается;
  приложение работает без сети, как и задумано для основного продукта.
- **Быстрый CI.** Один обязательный workflow на push: `tsc`, юнит-тесты, смоук и E2E. Публикация
  веб-версии на GitHub Pages и неподписанный APK — только вручную (`workflow_dispatch`): на каждый
  push тратилось ~2–3 минуты runner-времени без пользы для Android.
- **Релиз-инженерия проще.** Версия и `versionCode` — в `package.json` (`version`, `androidVersionCode`);
  `build-apk.sh` читает их оттуда, манифест проверяется тестом. Убран неиспользуемый
  `scripts/smoke-web.mjs`.
- **Документы приведены к реальности:** README, HANDOFF, ARCHITECTURE, этот роадмап.

### 2.1.0 — «Скорость и размер» (следующая)

- **Разгрузка `App.tsx`:** экраны (`PlanScreen`, `JournalScreen`, `SpecsScreen`, `EstimateScreen`),
  панель инструментов, свойства, шторка экспорта, `ChangeLogEditor`, служебные компоненты — по файлам,
  без изменения поведения; тесты хуков (`useProjectHistory`, `useSnapshots`, `usePdfBackground`).
- **Размер APK:** сабсет PT Sans Regular/Bold до используемых глифов, проверка PDF на кириллице через
  `pdftotext`; убрать неиспользуемые ассеты.
- **Зависимости:** `xlsx` → ExcelJS или официальный SheetJS (паритетные тесты XLSX), 0 high в аудите;
  удалить `server/export.ts` + `pdfkit` + `@types/pdfkit`, обновить API-доки и тесты.
- **Тесты:** общий `tests/fixtures.ts`; прямые тесты хуков; бюджеты покрытия и размера бандла в CI;
  `npm run status` вместо ручных счётчиков в документации.
- **Готово, когда:** `App.tsx` <500 строк; APK ≤1,4 МБ; 0 high-уязвимостей; поведение подтверждено
  тестами, смоуком и E2E; стартовый бандл ≤450 КБ.

### 2.2.0 — «Поле и доступность»

- Системный размер шрифта (`textZoom`), тёмная тема и высокий контраст.
- Бюджет памяти рендера 6–8 Мпикс с предупреждением; векторный план в PDF вместо растра 1600 px.
- Диагностика в интерфейсе: занятое место, версия WebView, экспорт журнала.
- Ручная проверка Android сокращается до трёх сценариев: запуск/проект, `.anooplan` через
  `content://`, печать/шаринг.

### 2.3.0 — «Документы и расчёт»

- Печатные формы: полный штамп ГОСТ 2.104, оглавление на второй странице для длинных документов.
- Смета: НДС, отдельные виды работ, единицы измерения; КП по разделам.
- Заполнение лотка: размеры на сегмент, коэффициент укладки/пучков, явная площадь плоских кабелей.
- Сравнение снимков версий (diff).

## 5. Что не делаем

- **Сетевые функции** — не добавляем «между делом»; только отдельным решением владельца.
- **Kotlin-переписывание** — только при ежедневном стилусе/A1+ или если WebView начнёт блокировать
  развитие; промежуточный вариант — нативная растеризация PDF.
- **Google Play, подписки, маркетплейс** — не влияют на основной сценарий.
- **Автодеплой Pages** — только вручную; решение «убрать Pages совсем» — за владельцем.

## 6. Определение готовности итерации (DoD)

1. `npx tsc --noEmit`, `npm test`, `npm run smoke`, `npm run test:ui` — зелёные; покрытие не упало.
2. Бюджеты: CI на push ≤110 с; стартовый бандл ≤450 КБ; APK: 2.0.0 ≤1,8 МБ, с 2.1.0 ≤1,4 МБ;
   0 high-уязвимостей после 2.1.0.
3. APK собран локально, подпись и сертификат совпадают; версия и `versionCode` — из `package.json`;
   установка и запуск проверены на эмуляторе; для Android-изменений — нужный ручной сценарий.
4. README («Что нового»), HANDOFF, ROADMAP обновлены; счётчики не правятся вручную (с 2.1.0 —
   `npm run status`).
5. **Скриншоты релиза: 1–3** (минимум один, максимум три), приложены к GitHub Release и в отчёт
   сессии; для невизуального изменения — один скриншот подтверждения.
6. Аннотированный тег `vX.Y.Z`, GitHub Release с APK, CI на `main` зелёный.

## 8. Риски

- **Сабсет шрифтов** может задеть редкие глифы — проверять PDF на кириллице и спецсимволах.
- **Замена XLSX-движка** может изменить файлы — сверять с эталонами и проверять чтение обратно.
- **Разгрузка `App.tsx`** без изменения поведения — только под смоуком/E2E, по одному экрану за коммит.
- **Веб-версия без автодеплоя** может отставать от `main` — публиковать вместе с релизом или убрать
  Pages совсем по решению владельца.
- **Сетевые функции** — только отдельным решением владельца; до этого тему не поднимать.
