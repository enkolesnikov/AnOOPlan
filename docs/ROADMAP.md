# План развития AnOOPlan — Android-first

Роадмап от **2026-10-25**. Фокус — **эффективность Android-приложения и процесса разработки**;
облако — в планах (дальняя перспектива), в `main` его нет. Релиз **2.5.0 «Поле и доступность»** добавил
сегментные размеры КНС, доступность (textZoom, тёмная тема, контраст), бюджет памяти рендера 8 Мпикс и
инженерный долг (ESLint, fixtures, lcov для Codacy). Следующая — **2.6.0 «Документы и расчёт»**;
фитинги/крепления по решению владельца не считаются — важны только углы коробов.

## 1. Что сделано в 2.5.0

- **Сегментные размеры КНС:** у сегмента можно задать своё сечение (диаметр/Ш×В/площадь), и одна трасса
  может содержать разные лотки и трубы. Поля необязательные и наследуются от трассы поле в поле;
  миграция нормализует числа и мусор, API отклоняет 0/отрицательные (422).
- **Учёт по сегментам:** `trayFill` и ведомость «Заполнение КНС» считают эффективное сечение участка,
  схема трасс получила колонку «Сечения», спецификация КНС — строки по каждому сечению (углы коробов
  относятся к основному сечению и не задваиваются), PDF печатает те же данные.
- **Подбор сечения** работает для трассы (только сегменты без своего сечения) и отдельно для сегмента.
- **Доступность:** системный размер шрифта Android применяется к WebView (textZoom 85–160 %), тёмная тема
  по `prefers-color-scheme`, высокий контраст/forced-colors, отключение анимаций, переносы вместо обрезки.
- **Память рендера:** бюджет 8 Мпикс (было 12) с предупреждением и советом «Вписать» вместо тихой деградации.
- **Инженерный долг:** `tests/fixtures.ts`, ESLint-конфиг и `npm run lint` в CI, lcov и загрузка покрытия
  в Codacy по `CODACY_PROJECT_TOKEN`, декомпозиция `sidebar.tsx`/`estimate-screen.tsx`.
- **Сохранено из 2.4.0:** спецификация КНС, подсистемы СКС, артикулы/производители, подбор сечения.
- **Проверено:** 244 юнит-теста, 231 проверка смоука, 2 E2E; покрытие 95,7/87,6/95,5 %; `tsc` и lint чисты.

## 5. Что не делаем

- **Фитинги, тройники, крепления** — по решению владельца; считаем только углы коробов.
- **Облако и real-time** — в планах на дальнюю перспективу; не возвращаем «между делом».
- **Kotlin-переписывание** — только при ежедневном стилусе/A1+ или если WebView заблокирует развитие.
- **DWG/IFC/десктопная САПР** — вне мобильного сценария.
- **Google Play, подписки, маркетплейс** — не влияют на основной сценарий.
- **Автодеплой Pages** — только вручную.

## 8. Риски

- **Тип по подстроке:** свой тип вроде «Лоток перфорированный» распознаётся как лоток — это ожидаемо;
  экзотические названия получают нейтральный цвет, пока пользователь не задаст свой.
- **Круглые КНС:** диаметр занимает поле `trayWidthMm` — при импорте старых проектов с шириной
  лотка и типом «Труба» площадь может отличаться; в интерфейсе подписи явно различаются.
- **Углы:** считаются как изменения направления между соседними сегментами; у несвязанной цепочки
  сегментов угол на стыке не учитывается. Для коробов это количество углов, а не фитингов.
- **Размеры:** только один этаж и расстояние по прямой (плоское); межэтажные размеры не входят.
- **Внешние линтеры (CodeFactor A, Codacy):** в 2.5.0 добавлен ESLint-конфиг (0 ошибок, шаг в CI),
  lcov и шаг загрузки покрытия в Codacy; декомпозированы sidebar и смета. Остались сложные
  `engine.ts`/`export-pdf.ts`/`properties-panel.tsx`/`MainActivity` — кандидаты на 2.6.0.
  Загрузка покрытия включится после добавления владельцем секрета `CODACY_PROJECT_TOKEN`.
- **Сегментные размеры:** незаданные поля наследуются от трассы поле в поле, а не «сечением целиком».
  Углы коробов относятся к основному сечению (наибольший метраж), чтобы не задваиваться; это осознанно.
- **textZoom:** диапазон 85–160 % — компромисс: вне него раскладка на телефоне разваливается.
  WebView может показывать крупнее на маленьких экранах; переносы и `min-height` это учитывают.
- **Память рендера:** 8 Мпикс ≈32 МБ RGBA. Для громадных листов качество клипа ограничено бюджетом,
  поэтому при сильном увеличении возможна «мягкая» картинка — приоритет у стабильности WebView.
- **Страница этажа и PDF:** если `floor.page` вне диапазона, оверлей не наносится — на листе
  печатается note, но лучше проверять «Страницу» в свойствах этажа при замене PDF.
- **Сабсет шрифтов** не содержит редких глифов (см. HANDOFF); базовые кириллица/латиница гарантированы.
- **XLSX-зависимость** — tarball с `cdn.sheetjs.com`: `npm ci` требует доступ к этому хосту.
- **Возврат к облаку** — только отдельным решением владельца.
