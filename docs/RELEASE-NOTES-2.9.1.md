# AnOOPlan 2.9.1 — «Точность и скорость»

Релиз закрывает остатки аудита 2.9: углы КНС на стыках и стояках, цены по сечению, подбор сечения,
честные миграции чисел, скорость ввода/перетаскивания, экспорт и прямые тесты UI-хуков. Офлайн-контракт
не изменился: разрешение только `VIBRATE`, `INTERNET` нет, внешних вызовов нет.

**APK:** `AnOOPlan-2.9.1.apk` · 1 612 488 Б · Android 7.0+ (minSdk 24, targetSdk 35)
**SHA-256 APK:** `926779d96bf8ef6a175b3841c9a4b31511e78aa34fa2f69547a4e592a0ca48d9`
**Подпись:** прежний сертификат SHA-256 `6431374c…92fe097`; versionCode 46.

## Что вошло

**Углы и КНС (C-04)**
- Углы считаются по цепочке сегментов от любого конца: обратный порядок хранения больше не обнуляет
  счёт, межэтажный стояк не рвёт цепочку.
- Стык двух трасс одного типа КНС даёт один угол на группу: после разделения трассы угол не теряется
  и не задваивается. Демо: Т1 = 1, Т3 = 1, итог «Лоток» = 2.

**Смета по сечениям (C-07)**
- `PriceItem.size` сопоставляется с эффективным сечением сегмента: «100×50», «100x50», «Ø20» и
  «Ø 20» приводятся к одному виду.
- Смета даёт отдельные строки «Лоток · 100×50» и «Стояк · 50×50» со своими ценами и суммами, а не
  одну строку «Лотки».
- Если сечения нет в прайсе, цена и сумма — `—`, а в предупреждениях указано, какого сечения не
  хватает. Первая попавшаяся цена не подставляется. Пустая трасса больше не добавляет строку 0 м и
  не обнуляет раздел.

**Подбор сечения (C-10)**
- Рекомендация не выдаётся, если хотя бы у одного кабеля анализируемых сегментов неизвестно сечение
  или количество.
- Учитываются только кабели этого сегмента (или сегментов без своего сечения для трассы), а не
  соседних участков; самый толстый кабель также берётся только оттуда.

**Миграции (C-09)**
- `quantity=0` остаётся нулём и даёт ошибку количества, а не превращается в 1.
- `NaN`/`null` количества и запасов сохраняются как «неизвестно» и диагностируются; JSON-цикл
  `NaN → null → NaN` не подменяет повреждение нулём. В журнале, CSV и PDF такие значения — прочерк,
  а не «NaN».

**Скорость (P-01…P-03)**
- Перетаскивание обновляется через `requestAnimationFrame`, проект не клонируется на каждый кадр,
  тяжёлые производные замирают до отпускания.
- `totals` берутся из готового `cableCalcs`; `trayFill` строит индекс «сегмент → кабели» один раз
  (11,6 → 1,9 мс median на 2000 сегментах, ~6×); `segmentIndex` кэшируется на структуру проекта.
- В Chromium на 2000 сегментах drag идёт 16,7 мс/кадр (60 Гц, 0 long tasks); ввод — 40–46 мс на
  символ (p95 51–55): каждая правка инвалидирует memo и рендерит 9655 узлов. Критерий 16 мс для
  ввода не достигнут, culling вынесен в 3.0.
- Безымянные `mutate` склеиваются в один шаг undo, как и именованные.

**Экспорт и сервер (E-10…E-12, P-05)**
- Лист «Предупреждения» включает `domainWarnings`.
- Пустое имя проекта даёт «Проект.pdf/.xlsx/.csv/.anooplan», а не `.pdf`.
- Серверный restore переименовывает `idb:`-PDF в content-addressed серверный id и отказывает
  висячему `idb:`-id; повторное восстановление переиспользует PDF.
- Хешированные ассеты отдаются с `immutable`, HTML — с `no-cache`.

**Тесты и supply chain**
- Прямые тесты `useSnapshots`/`useProjectIo`, сценарий «удалить → undo → Blob жив».
- Release-гейт: `npm run size`, проверка versionName/versionCode, отсутствия `INTERNET`, размера
  ≤4 МБ и непустого `ANDROID_CERT_SHA256`; инструменты Android сверяются по SHA-256, обход проверки
  при переопределении запрещён; пароль keystore не передаётся в argv.

**Доступность и WebView (A-03, S-07)**
- Кнопка закрытия error-баннера подписана для скринридера.
- JS-мост проверяет origin страницы, `allowContentAccess=false`, неизвестные схемы блокируются,
  редирект на чужой origin возвращает на стартовую страницу.

## Осталось честно

Рендер плана из 2000 сегментов всё ещё перерисовывает все узлы: culling по видимой области — 3.0.
Список проектов хранится одной записью localStorage (F-11), серверный GC и фото в серверном режиме —
3.0. Установка на физическое устройство и полевой WebView — за владельцем. Подробности — в
[ROADMAP.md](ROADMAP.md), [AUDIT-2.9.md](AUDIT-2.9.md).

**Установка:** скачайте APK на телефон → откройте файл → «Установить». Все данные остаются
на устройстве, интернет приложению не нужен.
