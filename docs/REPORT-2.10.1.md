## Демо-ревизия

Полный разбор — [DEMO-REVIEW-2.10.1.md](DEMO-REVIEW-2.10.1.md). Три независимых критика
(планшет, телефон, сметчик) прошли демо вслепую, два круга.

**Круг 1 — что нашли и что закрыто:**

| Критик | Находка | Статус |
|---|---|---|
| Планшет | Колонтитул PDF печатал дату экспорта, а не дату документа (15.10.2026 vs 23.11.2026) | исправлено |
| Планшет/сметчик | Стоимость кабелей в плашке итогов 7 724,38 ₽ против 7 724,00 ₽ в смете | исправлено (округление сметы) |
| Планшет | Листы планов в разных масштабах: последний (с резервом под подписи) мельче | исправлено (общий масштаб) |
| Планшет | В журнале PDF нет строки «Итого» — только плашка на листе плана | исправлено |
| Планшет | Подытог КНС разрывался: «Итого по подсистеме:» и имя ниже | исправлено (одной строкой) |
| Планшет | На 1024×768 панель свойств нельзя закрыть | исправлено (кнопка закрытия) |
| Сметчик | XLSX «Схема трасс»: в «Сегментов» стояло число трасс | исправлено |
| Сметчик | XLSX журнала: служебная колонка «Трасса (ID)» с UUID | убрана |
| Сметчик | Автофильтр КП накрывал строки итогов (A5:B13) | исправлено (A5:B8) |
| Сметчик | В XLSX «сырые» значения 665.9499999999999 и SUM-мусор | деньги округлены до копейки |
| Сметчик | При vatRate=150 и ценах без НДС пропадало «Итого до НДС» | исправлено (net = total) |
| Телефон | FAB «Свойства» и undo/redo перекрывали таблицы и перехватывали тапы | скрыты на документных экранах |
| Телефон | «＋ Кабель» сжималась по буквам, имя проекта обрезалось, вкладки рвались | исправлено (CSS) |
| Телефон | Тач-цели 40 px | ≥44 px |
| Телефон/сметчик | ISO-дата в UI, двойная точка в примечании | исправлено |

**Отклонено с обоснованием:** легенда КНС и номера трасс на листе плана (P1 критика-планшета) —
лист плана печатается как подложка с подписями оборудования и пинов, легенда остаётся на экране;
выносится в 3.0 вместе с масштабной линейкой. Замечание «все кабели с ручной ценой, справочник
не влияет» — продуктовое решение (ручная цена приоритетнее по контракту 2.10.0), вынесено
в ROADMAP как «нужно решение».

**Круг 2:** критические пункты перепроверены теми же критиками на пересобранной версии
(итог — в журнале проверок ниже).
