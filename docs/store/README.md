# Store-иконки AnOOPlan

- `anooplan-512.png` — 512×512 RGBA, альфа-канал полностью непрозрачный; подходит для RuStore и Google Play (32-bit PNG).
- `anooplan-1024.png` — 1024×1024 RGBA, мастер для будущих площадок и пересборок.

Иконки собраны из Android adaptive icon (`android/res/drawable/ic_launcher_foreground.xml` и
`ic_launcher_background.xml`), а не апскейлом 192×192. Фон заполняет весь квадрат, без прозрачных
краёв. Палитра: фон `#122936`, сетка `#1A3746`, трасса `#38C6C9`, точки `#FFFFFF`.

Пересобрать:

```bash
python3 scripts/make-store-icons.py
```


## Скриншоты для RuStore

Каталог `screenshots/` — телефонные PNG **1080×1920** (9:16), RGB, без системных панелей и рамок.
RuStore принимает 3–10 штук на один тип устройств; загружаются в этом порядке:

1. `01-plan.png` — план с трассой и длинами сегментов;
2. `02-equipment.png` — список оборудования;
3. `03-estimate.png` — смета и коммерческое предложение;
4. `04-templates.png` — шаблоны проектов.

Требования RuStore: PNG/JPG до 3 МБ, максимум 2160×3840, рекомендуемое 16:9. Эти файлы
подготовлены из текущей 2.8.5 на демо-проекте «Офис» с отдельной PDF-подложкой.
